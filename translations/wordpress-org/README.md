# WordPress.org translation proposals

These readme PO files contain 57 Spanish proposals each. Their source strings were extracted from the released 1.0.2 readme using WordPress.org's official readme and Markdown parsers and the extraction expressions in its `Readme_Import` class. The bundled software catalogue contains 84 strings.

Run `python scripts/prepare_translation_imports.py` to produce eight upload files under `dist/translations-1.0.2`: software and readme for es_ES/es_CR in Development and Stable. This prepares files only.

On 16 November 2026, Development and Development Readme contained all proposals for both locales, in Waiting status and with zero warnings. Stable and Stable Readme were not available yet. Recheck the project before importing there, and compare its exported original strings with the prepared files if the source readme has changed.

Importing proposals does not approve translations or publish official language packs. The account had no approval permission for BAC. The PTE request is a draft for the maintainer to review and send. The installed plugin already includes Spanish independently of that review.
